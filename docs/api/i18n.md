# i18n 层 API

`error_system::i18n` ｜ 头文件目录：`error_system/i18n/`

多语言国际化模块，为错误码消息与子系统/模块名称提供 locale 化的查询能力，不依赖 ICU / gettext。locale 状态统一由 `config::i18n_config_t` 管理，避免双源配置不同步。

---

## locale_t

头文件：`error_system/i18n/locale.h`

语言区域强类型枚举，覆盖常用语言区域，替代裸字符串提供类型安全的 locale 标识。

### 枚举值

| 值 | 名称 | 值 | 名称 |
|---:|------|---:|------|
| 0 | `en_US` | 5 | `fr_FR` |
| 1 | `zh_CN` | 6 | `de_DE` |
| 2 | `zh_TW` | 7 | `es_ES` |
| 3 | `ja_JP` | 8 | `ru_RU` |
| 4 | `ko_KR` | 9 | `pt_BR` |
| 10 | `it_IT` | 11 | `ar_SA` |
| 12 | `hi_IN` | 13 | `th_TH` |
| 14 | `vi_VN` | | |

常量 `LOCALE_COUNT = 15`，查找表 `LOCALE_TABLE` 为转换函数的唯一数据源。新增 locale 只需在枚举与表末尾追加，无需修改任何转换函数。

### 转换函数

| 函数 | 签名 | 说明 |
|------|------|------|
| `to_string` | `[[nodiscard]] inline constexpr std::string_view to_string(locale_t locale) noexcept` | 转字符串标识，非法值返回 `"en_US"` |
| `from_string` | `[[nodiscard]] inline constexpr locale_t from_string(std::string_view text) noexcept` | 从字符串解析，未识别返回 `en_US` |
| `is_valid` | `[[nodiscard]] inline constexpr bool is_valid(std::string_view text) noexcept` | 是否为已知 locale 标识 |

全部函数 `inline constexpr noexcept`，可用于编译期常量。

```cpp
constexpr auto name = i18n::to_string(locale_t::zh_CN);   // "zh_CN"
constexpr auto loc  = i18n::from_string("ja_JP");         // locale_t::ja_JP
static_assert(i18n::is_valid("ko_KR"));
```

## subsystem_module_catalog_t

头文件：`error_system/i18n/subsystem_module_catalog.h`

子系统/模块名称多语言目录单例，维护 `(subsystem_id, module_id) → (locale → 名称)` 的两级映射，供 `to_string()` 等可读输出场景使用。继承 `i_subsystem_module_resolver_t` 接口，供 core 层通过抽象接口查询。本类不持有 locale 状态，由调用方从 `config::i18n_config_t` 读取 locale 后显式传入。线程安全（`shared_mutex` 读多写少）。

### subsystem_module_info_t

定义于 `error_system/i18n/i_subsystem_module_resolver.h`。

| 字段 | 类型 | 默认值 |
|------|------|--------|
| `subsystem_name` | `std::string` | `"未知子系统"` |
| `module_name` | `std::string` | `"未知模块"` |

### i_subsystem_module_resolver_t 接口

定义于 `error_system/i18n/i_subsystem_module_resolver.h`。core 层通过此抽象接口查询，避免直接依赖具体目录类。

| 方法 | 签名 |
|------|------|
| `resolve_subsystem_module` | `[[nodiscard]] virtual subsystem_module_info_t resolve_subsystem_module(locale_t output_locale, locale_t fallback_locale, uint16_t subsystem_id, uint16_t module_id) const noexcept = 0` |

### 单例与解析器

| 方法 | 签名 | 说明 |
|------|------|------|
| `instance` | `static subsystem_module_catalog_t& instance() noexcept` | 单例实例（`call_once` 保证线程安全） |
| `get_default_subsystem_module_resolver` | `[[nodiscard]] i_subsystem_module_resolver_t* get_default_subsystem_module_resolver() noexcept` | 自由函数，返回单例的接口指针，供 core 层延迟绑定 |

### 注册

| 方法 | 签名 | 说明 |
|------|------|------|
| `register_subsystem_module` | `void register_subsystem_module(locale_t locale, uint16_t subsystem_id, uint16_t module_id, std::string_view subsystem_name, std::string_view module_name) noexcept` | 注册指定 locale 的名称，已存在则静默跳过 |
| `register_subsystem_module` | `void register_subsystem_module(uint16_t subsystem_id, uint16_t module_id, std::string_view subsystem_name, std::string_view module_name) noexcept` | 便捷重载，默认 `zh_CN` |

### 查询

| 方法 | 签名 | 说明 |
|------|------|------|
| `get_subsystem_module_info` | `[[nodiscard]] subsystem_module_info_t get_subsystem_module_info(locale_t locale, locale_t fallback_locale, uint16_t subsystem_id, uint16_t module_id) const noexcept` | 指定 locale + 回退 locale |
| `get_subsystem_module_info` | `[[nodiscard]] subsystem_module_info_t get_subsystem_module_info(locale_t locale, uint16_t subsystem_id, uint16_t module_id) const noexcept` | 回退 `zh_CN` |
| `get_subsystem_module_info` | `[[nodiscard]] subsystem_module_info_t get_subsystem_module_info(uint16_t subsystem_id, uint16_t module_id) const noexcept` | 便捷重载，使用 `zh_CN` |
| `resolve_subsystem_module` | `[[nodiscard]] subsystem_module_info_t resolve_subsystem_module(locale_t output_locale, locale_t fallback_locale, uint16_t subsystem_id, uint16_t module_id) const noexcept override` | 实现 `i_subsystem_module_resolver_t` 接口 |

### 清理

| 方法 | 签名 | 说明 |
|------|------|------|
| `clear` | `void clear() noexcept` | 清空所有映射 |
| `clear_locale` | `size_t clear_locale(locale_t locale) noexcept` | 清空指定 locale，返回被清除条目数 |

```cpp
auto& catalog = subsystem_module_catalog_t::instance();
catalog.register_subsystem_module(locale_t::zh_CN, 101, 1, "交易服务", "订单模块");
catalog.register_subsystem_module(locale_t::en_US, 101, 1, "Trade Service", "Order Module");
auto info = catalog.get_subsystem_module_info(locale_t::en_US, locale_t::zh_CN, 101, 1);
// info.subsystem_name == "Trade Service"
```

## i18n_t

头文件：`error_system/i18n/i18n.h`

多语言消息目录单例，为错误码提供 locale 化的消息查询能力。使用两级哈希（`locale → code → message`），`shared_mutex` 读多写少场景。locale 状态委托给 `config::i18n_config_t`。

类型别名：`message_t = std::string`，`code_identity_t = code_t`。

### 单例

| 方法 | 签名 |
|------|------|
| `instance` | `static i18n_t& instance() noexcept` |

### 注册消息

| 方法 | 签名 | 说明 |
|------|------|------|
| `register_message` | `void register_message(locale_t locale, error_code_t code, std::string_view message) noexcept` | 注册单条消息 |
| `register_messages` | `size_t register_messages(locale_t locale, const std::vector<std::pair<error_code_t, std::string_view>>& entries) noexcept` | 批量注册，返回实际注册数 |

### 查询消息

| 方法 | 签名 | 说明 |
|------|------|------|
| `get_message` | `[[nodiscard]] std::string get_message(locale_t locale, error_code_t code) const noexcept` | 显式 locale 查询 |
| `get_message` | `[[nodiscard]] std::string get_message(error_code_t code) const noexcept` | 从 `i18n_config_t` 解析输出 locale 查询 |

回退路径：**指定/output locale → default locale → 空 string**。决策树详见 [决策树 · 4](../decision_tree.md#4-i18n-消息查询回退路径)。

### locale 管理

以下方法委托给 `config::i18n_config_t`，保留接口以兼容现有调用方。

| 方法 | 签名 | 说明 |
|------|------|------|
| `set_default_locale` | `void set_default_locale(locale_t locale) noexcept` | 设置默认 locale |
| `get_default_locale` | `[[nodiscard]] locale_t get_default_locale() const noexcept` | 获取默认 locale |
| `set_active_locale` | `void set_active_locale(locale_t locale) noexcept` | 设置输出 locale |
| `clear_active_locale` | `void clear_active_locale() noexcept` | 清除输出 locale，回退到默认 |
| `get_active_locale` | `[[nodiscard]] std::optional<locale_t> get_active_locale() const noexcept` | 获取输出 locale，未设置返回 `nullopt` |

### 管理与统计

| 方法 | 签名 | 说明 |
|------|------|------|
| `clear_locale` | `size_t clear_locale(locale_t locale) noexcept` | 清除指定 locale 所有消息，返回清除数 |
| `clear_all` | `void clear_all() noexcept` | 清除所有 locale 消息 |
| `get_locales` | `[[nodiscard]] std::vector<locale_t> get_locales() const noexcept` | 获取已注册 locale 列表 |
| `message_count` | `[[nodiscard]] size_t message_count(locale_t locale) const noexcept` | 指定 locale 的消息数量 |

```cpp
auto& catalog = i18n_t::instance();
catalog.register_message(locale_t::zh_CN, ERR_DB_TIMEOUT, "数据库连接超时");
catalog.register_message(locale_t::en_US, ERR_DB_TIMEOUT, "Database connection timeout");
catalog.set_active_locale(locale_t::en_US);
catalog.get_message(ERR_DB_TIMEOUT);  // "Database connection timeout"
catalog.clear_active_locale();        // 回退到 default → "数据库连接超时"
```
